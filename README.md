# FORMLORE: Scary Masterpieces collection notes

A small static site of collection notes for FORMLORE's Scary Masterpieces series: 36 old-master works (witches, death, demons and temptations, ghosts and yokai, and Bocklin's Island of the Dead). Each work has its own page with the artist, date, medium, museum and a link to the museum's own record, plus a short original note.

Published at https://seeeyi.github.io/formlore-site/

## What is in here

- `index.html`, theme pages, `works/`, `about/`: plain HTML and one CSS file, no JavaScript and no build step on the server.
- `img/`: web-sized images (about 1000 px, under 300 KB each) and thumbnails, from the open-access collections of the Cleveland Museum of Art, the Metropolitan Museum of Art and the National Gallery of Art.
- `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`: discovery files. Note that `robots.txt` only takes effect at a domain root; on a GitHub Pages project site it is informational.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

## How it is generated

The pages are generated by a Python script (`build.py`) from a curated works list. All internal links are prefixed from the path of the base URL, so the same build works at a domain root or under a project path:

    BASE_URL=https://seeeyi.github.io/formlore-site python3 build.py
